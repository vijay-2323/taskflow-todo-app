TaskFlow — Python To-Do List App

TaskFlow is a desktop To-Do List application built with Python, CustomTkinter, and SQLite.

Features
Add and delete tasks
Set task priorities
Add task descriptions and due dates
Mark tasks as completed
Search tasks by title
View total, pending, and completed task counts
Save tasks locally using SQLite
Modern dark-themed graphical interface
Requirements
Python 3.10 or newer recommended
pip
Installation
Clone or download this repository.
Open the project folder in your terminal.
Install the required dependency:
   python -m pip install -r requirements.txt

Run the application:
   python main.py


On Windows, you can also use:

py main.py

Technology Stack
Python
CustomTkinter
SQLite
Tkinter
Data Storage

Tasks are stored locally in a SQLite database file named tasks.db. This file is created automatically when the application runs.
